## Описание проекта
**CodeVibe** — это _плагин для IDE_, который добавляет элементы геймификации в процесс разработки. Он помогает _поддерживать мотивацию_, _отслеживает полезные привычки_ (частые коммиты, чистый код) и _поднимает настроение_.

## Список фич (ТЗ) 📃
*   **[Base]** Инициализация проекта.
*   **[Base]** Кнопка Hello World на панели инструментов.
*   **[Base]** Пункт в контекстном меню редактора.
*   **[Yellow]** Генератор Шуток (запрос к открытому API).
*   **[Yellow]** Конвертер Времени (перевод секунд в часы по горячей клавише).
*   **[Advanced] Система достижений (Achievements):**
    *   Окно со списком бейджей.
    *   Трекер коммитов («100 коммитов»).
    *   Трекер рефакторинга («10 рефакторингов»).
    *   Всплывающие уведомления о получении ачивки.

## Инструкция по запуску❗️
1. Клонируйте репозиторий на локальную машину.
2. Откройте проект в IDE (IntelliJ IDEA / PyCharm / VS Code).
3. Дождитесь загрузки зависимостей.
4. Запустите плагин через меню: `Run` -> `Run 'Plugin'`.
5. Откроется тестовая среда, где можно проверить работу плагина.
